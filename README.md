# おでかけ安心｜提出用サンプル

予定や準備をまとめて確認し、忘れ物を減らすための生活サポートWebアプリの提出用サンプルです。

## この公開版について

このリポジトリには、本人用の実データは含まれていません。

- Firebaseには接続しません
- 個人の予定・連絡先・予約情報などは含みません
- Googleカレンダー等の本人アカウントにも接続しません
- 初期状態は空です
- 入力した内容は、そのブラウザの `localStorage` にだけ保存されます

そのため、この公開版を見た人が入力しても、作者の個人用データには影響しません。

## 主な機能

- 予定の追加
- 日付・予定名・準備メモの記録
- 予定の編集・削除
- 予定の検索

## 試し方

`index.html` をブラウザで開くと利用できます。

## 再利用について

このコードはコピーして、自分用の予定や準備内容を入力・改造して利用できます。
公開版の保存先は各ブラウザ内のみです。複数端末同期やクラウド保存は含まれていません。

## 技術

HTML / CSS / JavaScript / localStorage
